# Browser Switcher Support

Official public issue tracker for **Browser Switcher for Mac**. This repository contains no application source code and is used only for support requests, bug reports, and feature suggestions.

**Browser Switcher for Mac 官方公开问题反馈中心。** 本仓库不包含应用源码，仅用于技术支持、错误报告和功能建议。

## Submit an issue / 提交问题

- [Report a bug / 报告错误](https://github.com/LeiZiKang/browser-switcher-support/issues/new?template=bug_report.yml)
- [Request a feature / 功能建议](https://github.com/LeiZiKang/browser-switcher-support/issues/new?template=feature_request.yml)
- [View existing issues / 查看已有问题](https://github.com/LeiZiKang/browser-switcher-support/issues)

Before opening a new issue, please search existing issues first. English and Chinese are both welcome.

提交新问题前，请先搜索是否已有相同问题。中文和英文均可。

## Helpful information / 建议提供的信息

- macOS version / macOS 版本
- Browser Switcher version / Browser Switcher 版本
- Browser name and version / 浏览器名称及版本
- Steps to reproduce / 复现步骤
- What you expected and what happened / 预期结果与实际结果
- Screenshots, if helpful / 必要时附上截图

## Privacy / 隐私提醒

GitHub Issues are public. Please do not include passwords, cookies, account credentials, private URLs, or other sensitive information.

GitHub Issues 内容公开可见，请勿提交密码、Cookie、账号凭据、私人网址或其他敏感信息。

Thank you for helping improve Browser Switcher. / 感谢你帮助改进 Browser Switcher。
